sticker-video-producer｜贴纸风口播视频工坊

把一段口播稿，做成有视觉隐喻、纸片动画、旁白和字幕的贴纸风短视频，并生成可继续编辑的剪映专业版草稿。适合知识科普、文化讲解、旅行见闻和故事型口播。

主要功能：
- 口播拆分镜：提炼每段文案的核心意思，设计视觉隐喻、关键纸片、背景色和入场顺序。
- 拼贴画面生成：制作半调照片、撕纸边缘、彩色卡纸和纸面阴影，也能接入已有静帧。
- 纸片组装动画：支持接入 Gemini 或即梦 Seedance，以首尾帧控制构图，安排滑入、弹入、旋转和落位动作。
- 本地配音与字幕：通过 Voicebox 使用本人或已获授权的音色，逐句生成旁白，并按实际音频长度生成 SRT 字幕。
- 剪映草稿组装：自动排列镜头、适配时长，将画面、旁白和字幕放入独立轨道，方便继续剪辑。
- 分阶段确认与续做：先确认分镜，再确认静帧；支持只完成指定阶段、局部重做和复用已有素材。
最终交付包括：镜头方案、静帧、逐镜视频、WAV 旁白、SRT 字幕和剪映草稿。
